# YDM

این پروژه یک برنامه دانلود منیجر هست که شما با اون میتونید فایل فایل ویدیو های یوتیوب رو به سادگی و با فرمت و کیفیت دلخواه دانلود کنید.

همچنین این برنامه به شما امکان دانلود فقط فایل صوتی یک ویدیو از یوتیوب رو برای شما فراهم میکنه.

#روش دانلود از یوتیوب

1_ برای دانلود از یوتیوب فقط کافیه که لینک ویدیو رو از یوتیوب کپی(copy) و در برنامه (paste)کنید.

2_ سپس کیفیت مورد نظر رو انتخاب کنید.

3_ روی گزینه افزودن به صف کلیک کنید.

4_ روی دانلود صف کلیک کنید تا فایل مورد نظر شما دانلود شود.



#Adobe connect downloader

1_ برای دانلود فایل pdf از Adobe connect کافیه که اول هر دو فایل پیوست شده را دانلود کنید.

2_ وارد مرورگر گوگل کروم (google chrome) شوید.

3_ با کلیک روی سه نقطه بالای صفحه در سمت راست و انتخاب گزینه Manage extensions در قسمت Extensions (سه نقطه<Extensions<Manage extensions) وارد بخش مدیریت افزونه ها شوید.

4_ در بالا سمت راست گزینه Developer mode رو فعال کنید.

5_ روی گزینه load unpacked کلیلک کنید و در پنجره باز شده وارد فایلی که در ابتدا استخراج کردید شوید و سپس وارد پوشه extension و سپس chrome شوید و سپس روی گزینه select folder کلیک کنید (AdobeConnect_Integration_...<extension<cchrome).

6_ برنامه YouTube downloader رو باز کنید و وارد کلاس شوید.

7_ با مرورگر گوگل کروم وارد Adobe connect شوید و دکمه F12 را روی کیبورد خود فشار دهید.

8_ حالا باید منتظر بمانید تا فایل pdf روی Adobe connect آپلود شود و به محض آپلود شدن pdf برنامه دانلودر به شما یک اعلان نشان میدهد که آیا میخواهید فایل pdf را دانلود کنید و شما میتونید فایل pdf رو دانلود کنید.
